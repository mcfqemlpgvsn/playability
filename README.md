## 🤖 Overview

PlayAbility bridges accessibility technologies — eye tracking, voice recognition, switch access — with popular games, allowing players with disabilities to game independently.

Whether you're a newcomer or a veteran, PlayAbility provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Gaze Control** | Use eye gaze as a mouse for exploration and basic interaction |
| **Voice Commands** | Map spoken words to in-game actions and macros |
| **Switch Access** | Full gameplay via one-switch or two-switch scanning control |
| **Profile Library** | Community profiles for popular game genres and titles |
